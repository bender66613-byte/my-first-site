# Моя первая страница

Небольшой персональный сайт на обычном HTML и CSS. Ничего устанавливать не нужно — открой `index.html` в браузере.

## Что изменить в первую очередь

- В `index.html` замени имя «Бенде» и приветственный текст на свои.
- Напиши о своих настоящих интересах в карточках.
- Замени `hello@example.com` на свою почту.

## Публикация

Этот проект можно бесплатно опубликовать через GitHub Pages. После создания аккаунта GitHub загрузи файлы в новый репозиторий и включи Pages в настройках репозитория.
